# Africa Unearthed

An educational, interactive one-page map exploring the Ghana, Mali, and Songhai empires alongside broad present-day gold and petroleum regions in Africa.

## View the site

Open `index.html` in a browser. The map layer buttons work without a build step or external dependencies.

To publish it as a website, enable GitHub Pages for this repository and select the `main` branch and `/ (root)` as the source in **Settings → Pages**. The resulting URL will appear in the Pages settings.

## Important context

- Historical empire zones are simplified approximations, not exact borders.
- Resource markers are illustrative regional indicators, not verified deposit locations, reserves, or prospectivity estimates.
- Historical wealth and trade do not establish the presence of undiscovered oil or gold.
- Consult up-to-date national geological surveys and official energy data for research.
